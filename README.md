🏭 Motor Temperature Diagnostics

This project checks component health based on morning temperature readings. It utilizes machine learning models to classify temperatures into specific health statuses.

📂 Project Structure & Core Logic

logic2.ipynb (Model Training Pipeline)

This Jupyter Notebook contains the core model training code.

Data Source: Loads initial data from measures_v2.csv and extracts the coolant, stator_winding, and ambient columns into NumPy arrays.

Model Logic: Initializes a StandardScaler and trains three separate LogisticRegression models individually for coolant, stator winding, and ambient temperatures. The models are trained on 20-item samples generated by a custom representative_sample function.

Targets: Uses hardcoded arrays categorizing the components as 'Optimal', 'Check', or 'Critical'.

Interface: Prompts the user via the terminal with inputs like "Enter ambient temp: " to collect the data, and prints the final predictions directly to the terminal output.

app.py (Interactive Streamlit Interface)

This script serves as a Streamlit web application with a centered layout and the title "Motor Diagnostics".

Data Source: Loads its initial data from a file named Raw data.csv.

Model Logic: Mirrors the Jupyter Notebook logic by extracting the arrays, sampling them, and fitting the three LogisticRegression models directly in the script.

User Interface: Features three clean numeric input fields for "Ambient Temp (°C)", "Stator Temp (°C)", and "Coolant Temp (°C)", all defaulting to 0.0.

Output: Diagnostic results are calculated when the user clicks the "Submit Temps" button, outputting the predictions with corresponding colors based on the array output: "CRITICAL 🔴", "CHECK 🟡", or "OPTIMAL 🟢".

🚀 How to Run the Application Locally

To launch the interactive web interface on your local machine, follow these steps:

1. Install the required dependencies
The project relies on specific Python libraries. Ensure you have them installed in your environment by running:

pip install streamlit numpy pandas scikit-learn


2. Execute the Streamlit run command
Open your terminal (or Git Bash), navigate to the root directory of this project where app.py is located, and run the following command:

streamlit run app.py


3. View the Application
Once the command executes successfully, Streamlit will spin up a local server. A new tab should automatically open in your default web browser displaying the Motor Diagnostics application (typically at http://localhost:8501). To stop the server at any time, press Ctrl + C in your terminal.
