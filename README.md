# Engineering-temp-classifier
## 📂 Project Structure & Core Logic

### `logic 2.ipynb` (Model Training & Development Pipeline)
This Jupyter Notebook serves as the primary research and development environment for the machine learning model. It contains the complete end-to-end data processing and training pipeline. Within this file, the raw dataset is ingested, cleaned, and explored through various exploratory data analysis (EDA) techniques to identify underlying patterns and correlations. It handles all the feature engineering required to format the data (such as thermal telemetry or sensor readings) for the machine learning algorithms, executes the actual model training process, and thoroughly evaluates the model's performance metrics. Finally, this notebook serializes and exports the fully trained model (typically as a `.pkl` or `.joblib` file) so it can be deployed for real-world predictions.

### `app.py` (Interactive Streamlit Interface)
This script is the deployment engine that transforms the trained machine learning model into a fully functional, interactive web application. Built using the Streamlit framework, `app.py` acts as the bridge between the complex backend logic and the end-user. It loads the saved model weights generated by the Jupyter Notebook and constructs the graphical user interface. Furthermore, it contains the logic to capture real-time user inputs, format those inputs precisely how the model expects them, and instantly render the model's predictive classifications on a clean, accessible front-end dashboard.

## 🚀 How to Run the Application Locally

To launch the interactive web interface on your local machine, follow these steps:

**1. Install the required dependencies**
Ensure you have Streamlit and the necessary machine learning libraries (such as Pandas, Scikit-Learn, or XGBoost) installed in your Python environment. You can install Streamlit directly via your terminal:
`pip install streamlit`
*(If a `requirements.txt` file is provided in this repository, install all dependencies at once by running: `pip install -r requirements.txt`)*

**2. Execute the Streamlit run command**
Open your terminal (or Git Bash), navigate to the root directory of this project where `app.py` is located, and run the following command:
`streamlit run app.py`

**3. View the Application**
Once the command executes successfully, Streamlit will spin up a local development server. A new tab should automatically open in your default web browser displaying the application. If it does not open automatically, you can manually navigate to the Local URL provided in your terminal output (typically `http://localhost:8501`). To stop the server at any time, press `Ctrl + C` in your terminal.
